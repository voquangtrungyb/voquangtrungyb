### About Me

Hi there! I'm **Vo Quang Trung**, a Software Engineering student passionate about crafting real-world software solutions that combine **fluid mobile user experiences (Flutter / Android)** with **robust, clean-architecture backends (Java Spring Boot / Golang)**.

- **Mobile Development:** Specialized in building high-performance cross-platform apps with **Flutter** and native **Android SDK**.
- **Backend & Architecture:** Architecting RESTful APIs using **Clean Architecture**, with reliable data storage in **PostgreSQL & SQL Server**.
- **Growth Mindset:** Constantly expanding system design knowledge, eager to collaborate on production-grade systems and explore innovative technologies.
- **Beyond the Screen:** Tech enthusiast, UI/UX explorer, and casual gamer in my downtime.
